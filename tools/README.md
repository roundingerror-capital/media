# Render tools (Penny)
Public-safe helpers used to render Rounding Error posts: 1080×1920 Shorts/Reels and 1080×1350 carousels.
Fonts: Archivo and IBM Plex Mono (SIL Open Font License). Sprites: original characters.
Every number in a post comes from a Theo fact sheet; nothing private lives here.

## Pixel art rule (the boss 2026-11-01)
Every piece of pixel art in a video, cover, asset or canvas artboard follows the `pixel-art-craft` skill: draw at the final size,
silhouette first, 3-5 tone hue-shifted ramps per material, one light from the top-left, no pillow shading, banding or stray pixels,
clusters of 2+ pixels, black only for eyes, and the readability checks (1x, 4x, silhouette, grayscale, on the real background) before
anyone sees it. Scale sprites with NEAREST only. Text, charts and UI are not pixel art and keep the brand type rules.
