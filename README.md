# media
  Public media for @roundingerror.capital posts. Real trades, not advice.

## Retention

- Posted videos stay here as the public audit trail for each numbered trade. Don't delete them: git keeps history, so deleting saves no space.
- Metricool copies each video to its own storage when the post is scheduled, so a published post never depends on this repo.
- GitHub recommends keeping a repo under 1 GB. At about 40 MB a month, this one is good for roughly two years. After that, start a new media repo for the year and keep this one as a read-only archive.
- Only public content goes here: no fund size, no account details, no personal data.
